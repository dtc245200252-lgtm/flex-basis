CSS Flexbox Master

Tìm Hiểu & Thực Hành Thuộc Tính flex-basis

Khám phá cách thuộc tính flex-basis kiểm soát kích thước cơ sở ban đầu của Flex Item trên trục chính (Main Axis).

📖

1. Khái Niệm & Cú Pháp Cơ Bản

flex-basis là thuộc tính trong CSS dùng để chỉ định kích thước cơ sở ban đầu của một Flex Item dọc theo trục chính (main axis) trước khi không gian trống còn lại được phân bổ thêm bởi flex-grow hoặc thu nhỏ lại bởi flex-shrink.

flex-basis: <length> | auto | initial | inherit;
🎯 Trục chính (Main Axis):
  • flex-direction: row → flex-basis xác định chiều ngang (width).
  • flex-direction: column → flex-basis xác định chiều dọc (height).
⚙️ Các giá trị thường dùng:
  • number (px, %, em, rem...): Kích thước cụ thể định trước.
  • auto (mặc định): Lấy theo width/height hoặc nội dung.
  • initial: Đưa về mặc định (auto).
  • inherit: Kế thừa từ phần tử cha.
Ví dụ 1

Sử Dụng flex-basis Với Đơn Vị px (Trục Ngang)

Trục chính mặc định là hàng ngang (flex-direction: row). Các phần tử có kích thước cơ sở chiều rộng lần lượt là 200px, 100px và 150px.

Container: display: flex; gap: 10px;
Item 1 flex-basis: 200px
Item 2 flex-basis: 100px
Item 3 flex-basis: 150px 
/* CSS Ví dụ 1 */
.container {
  display: flex;
  gap: 10px;
}
.item1 { flex-basis: 200px; }
.item2 { flex-basis: 100px; }
.item3 { flex-basis: 150px; }
Ví dụ 2

flex-basis Thay Đổi Theo flex-direction: column (Trục Dọc)

Khi flex-direction: column, trục chính xoay thành chiều dọc. Lúc này flex-basis: 100px sẽ kiểm soát chiều cao (height) của từng Item thay vì chiều rộng.

Container: display: flex; flex-direction: column; height: 500px; gap: 10px;
Item 1 flex-basis: 100px (chiều cao)
Item 2 flex-basis: 100px (chiều cao)
Item 3 flex-basis: 100px (chiều cao) 
/* CSS Ví dụ 2 */
.container {
  display: flex;
  flex-direction: column;
  gap: 10px;
  height: 500px;
}
.item {
  flex-basis: 100px; /* Chiều cao ban đầu */
  padding: 20px;
  background-color: lightgreen;
}
Ví dụ 3

Sử Dụng flex-basis Với Phần Trăm (%)

Khi đặt flex-basis: 50%, mỗi item chiếm kích thước cơ sở tương ứng 50% độ rộng của container theo trục chính, chia đều thành 2 cột tương xứng.

Container: display: flex; gap: 10px;
Item 1 flex-basis: 50%
Item 2 flex-basis: 50% 
/* CSS Ví dụ 3 */
.container {
  display: flex;
  gap: 10px;
}
.item {
  flex-basis: 50%;
  padding: 20px;
  background-color: lightcoral;
  box-sizing: border-box;
}
Ví dụ 4

Kết Hợp flex-basis Với flex-grow

Cả 3 Items ban đầu đều có kích thước xuất phát là flex-basis: 100px. Phần không gian dư thừa trong Container rộng 600px được chia theo tỷ lệ flex-grow: Item 1 (grow: 1), Item 2 (grow: 2), Item 3 (grow: 1). Do đó Item 2 mở rộng nhiều gấp đôi Item 1 và Item 3!

Container: width: 600px; display: flex; gap: 10px;
Item 1 basis: 100px | grow: 1
Item 2 basis: 100px | grow: 2 (Nhận x2 không gian thừa)
Item 3 basis: 100px | grow: 1 
/* CSS Ví dụ 4 */
.container {
  display: flex;
  width: 600px;
  gap: 10px;
}
.item1 { flex-basis: 100px; flex-grow: 1; }
.item2 { flex-basis: 100px; flex-grow: 2; }
.item3 { flex-basis: 100px; flex-grow: 1; }

7. Bảng Tóm Tắt & Ghi Nhớ Kiến Thức

Giá trị Mô tả công dụng Ứng dụng thực tế
flex-basis: 200px Đặt kích thước cơ sở ban đầu là 200px Cố định bề rộng/cao khởi điểm cho sidebar, card, nút bấm
flex-basis: 50% Đặt kích thước cơ sở bằng 50% theo trục chính Chia layout 2 cột đồng đều (chia 3 cột với 33.33%)
flex-basis: auto Lấy kích thước từ width/height hoặc theo nội dung bên trong Giá trị mặc định, tự co giãn theo nội dung phần tử
flex-basis: initial Khôi phục về giá trị mặc định của CSS (auto) Reset thuộc tính khi ghi đè CSS
flex-basis: inherit Kế thừa giá trị flex-basis từ phần tử cha Đồng bộ kích thước với container cha khi lồng flex

💡 Quy Tắc Vàng Cần Nhớ

Quy tắc 1

flex-basis phụ thuộc mật thiết vào flex-direction:
• row → tác động chiều ngang (Main Axis = Width).
• column → tác động chiều dọc (Main Axis = Height).

Quy tắc 2

flex-basis là kích thước xuất phát điểm.
Sau đó flex-grow sẽ chia thêm không gian dư thừa, còn flex-shrink sẽ co lại nếu thiếu không gian.
